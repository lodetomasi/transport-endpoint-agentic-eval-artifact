# `paper/figures/`

Nessuna immagine orfana: ogni figura e' rigenerata da uno script in `analysis/`, e una figura
che non lo e' non entra nel paper.

Una figura porta **una** claim. Le forme stanno nel grafico, le parole nella didascalia: le
annotazioni con coordinate a mano si ordinano in codice e si sovrappongono nel PDF, e nessun
controllo lo segnala. L'unico che le prende e' rendere la pagina e guardarla.
